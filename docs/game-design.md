研发： 徐志平　复旦大学　计算与智能创新学院　2026

## 世界观与主线

符文王国的守护龙诺克斯被未经验证的法术污染。勇者与巫师赛勒斯寻找失踪学徒艾琳，逐步识破先知的幻象，修复矿洞、驿站和档案设施，整理证词与观测数据，渡海追回契约，最后解除恶龙诅咒。16 周课程各对应基础与进阶两关，共 32 关；32 枚初印与铭印共同组成 16 组知识符文。

## 循环与视觉

地图行走 → 巫师对话 → 法术阅读 → 概念挑战 → 即时解释 → 符文与经验 → 下一关。32 关均配置独立景观，8 张2×2背景图集提供32个不同场景；每关按对应图集位置显示，保持同一像素艺术语言。主角进入交互半径后，巫师、法术碑、旅途之门和终章恶龙热区会发出柔和闪烁微光；E 键选择最近目标。每关共5题，包含原剧情题和4道专属补充题，共160题。全部答对才能获得符文并开放下一关，错误可重试，每题显示解析；题目进度本地保存，关闭或重启后续答。App 使用符文龙专属图标，提供 PNG、ICNS、ICO。

## 第 1 关：初醒 · 星火村

恶龙「诺克斯」吞噬了王国的知识符文。巫师赛勒斯递给你一盏灯：先学会把输入变成输出，才能踏上旅途。

教学：程序设计把问题分解为输入 Input、处理 Process、输出 Output。安装 Python，在 VS Code 选择解释器，运行 .py 文件；AI 插件可以草拟代码，但你需要读懂并验证。提示词应说明目标、输入、输出与约束。

实践：在本机配置 Python + VS Code，提交环境截图和附有提示词注释的新年程序。

## 第 2 关：导师的第一封信 · 烛光书房

赛勒斯发现失踪学徒艾琳留下的手稿：“先知只给答案，从不解释。”你们在书房重建她的第一道法术，学会把要求说清楚，找到前往工坊的线索。

教学：提示词越清晰越容易验证：指定 Python、输入年份、输出精确格式、要求注释，并给出样例。环境配置完成后应先运行最小程序确认解释器可用。

实践：在本机配置 Python + VS Code，提交环境截图和附有提示词注释的新年程序。

## 第 3 关：体魄 · 药剂工坊

炼金师需要按勇者的身高体重调配药剂。字符串不能直接参加数值运算，先把输入转化为数值。

教学：变量保存值；int 表示整数，float 表示浮点数，str 表示文本，bool 表示真或假。input 返回字符串，float/int 可做转换。+ - * / // % ** 是常见运算符；比较与逻辑运算用于判断。

实践：实现 BMI 计算器，请 AI 优化结构并解释输入转换与运算顺序。

## 第 4 关：月露配方 · 月露药圃

药圃精灵用比较符文封住了药箱。艾琳曾在这里救过受伤的旅人；她留下的配方提醒你，数值判断必须考虑临界值。

教学：比较运算返回 bool；and 要求两侧都成立，or 要求至少一侧成立，not 取反。比较表达式可连续书写。测试边界值有助于发现条件错误。

实践：实现 BMI 计算器，请 AI 优化结构并解释输入转换与运算顺序。

## 第 5 关：幻象 · 镜语林

镜中精灵声称它的每句咒语都正确。赛勒斯提醒你：看似可信的代码也可能调用不存在的函数。

教学：AI 可能虚构 API、遗漏边界或误解需求。用“目标 + 输入输出 + 约束 + 示例”优化提示词；查技术文档，用正常、边界和错误输入验证，记录失败原因与修正。

实践：记录 3 次 AI 编程失败：原提示词、错误、测试证据、修正提示词与结果。

## 第 6 关：先知的幻术 · 碎镜礼拜堂

镜中先知承诺“所有成绩都能直接求平均”。你用空列表打破幻象，找到艾琳的一页调试日志：未经验证的咒语正流向龙眠城堡。

教学：验证不能只用一个正常样例。零、空集合、边界数值与无效输入都可能揭示 AI 代码遗漏。不要为了让测试通过而改变真实需求；保留失败和修正记录。

实践：记录 3 次 AI 编程失败：原提示词、错误、测试证据、修正提示词与结果。

## 第 7 关：裂隙 · 调试矿洞

矿洞升降机被错误咒语卡住。用断点检查变量，用日志追踪流程，别让异常毁掉整座矿洞。

教学：SyntaxError 表示语法不合法；运行时错误发生在执行过程中，如 ZeroDivisionError；逻辑错误能运行却结果错误。断点暂停执行并观察变量，print 记录中间结果，try/except 处理预期异常。

实践：完成 20 分钟 W1–3 测验，修复预设错误并保存断点或日志证据。

## 第 8 关：升降机重启 · 水晶深井

矿工被困在深井。你在断点处发现矿车数量为零，捕获异常后给出可理解的提示。升降机重启，矿工告诉你艾琳去了回声峡谷。

教学：读取异常信息并定位具体语句。断点查看 count 的值，单步跟踪；日志记录输入和中间结果。只捕获预期异常，避免 except: 掩盖不相关错误。

实践：完成 20 分钟 W1–3 测验，修复预设错误并保存断点或日志证据。

## 第 9 关：岔路 · 回声峡谷

峡谷守卫藏起一个数字。条件分支选择道路，循环让勇者不断尝试，直到猜中。

教学：if/elif/else 根据布尔条件选分支；for 遍历序列，while 在条件为真时重复。break 结束循环，continue 跳过本轮。减少深层嵌套有助于理解流程。

实践：开发含简单/困难模式的猜数字游戏，并解释循环何时结束。

## 第 10 关：走出循环迷宫 · 回环石阶

石阶被循环咒语困住，每走一步都会回到原处。赛勒斯让你寻找更新条件；终止循环后，通向驿站的路显现出来。

教学：while 循环必须让条件有机会改变；break 可提前结束。嵌套循环需要逐层推演，提早判断无效输入有助于减少嵌套。

实践：开发含简单/困难模式的猜数字游戏，并解释循环何时结束。

## 第 11 关：行囊 · 双子驿站

勇者把药剂装进行囊，把不可改变的地图坐标刻在石板上。列表可以修改，元组记录固定组合。

教学：list 有序且可变，支持 append、索引、切片；tuple 有序但不能替换元素。索引从 0 开始，负索引从末尾计数，切片左闭右开。

实践：编写列表版成绩管理系统，支持添加、查询与平均分。

## 第 12 关：不可改写的坐标 · 霜峰双塔

雪风吹乱了行囊，只有石板上的坐标没有改变。你用序列整理补给，把艾琳留下的固定坐标交给双塔守卫，换来入城许可。

教学：列表可以增删改元素；元组禁止替换自身元素。对列表的别名修改会影响同一个对象，复制列表可保留独立副本。

实践：编写列表版成绩管理系统，支持添加、查询与平均分。

## 第 13 关：名册 · 秘钥城

城门需要按姓名找成绩，还要剔除重复的通行印记。用字典建立对应关系，用集合保留唯一值。

教学：dict 将键映射到值，键需可哈希且唯一；set 保存不重复元素，可求交集、并集和差集。常见字典/集合查询平均 O(1)，列表查找通常 O(n)，实际性能需结合数据规模验证。

实践：改写字典版成绩系统，并比较列表与字典按姓名查询的方式。

## 第 14 关：重复印记 · 黄金秘钥库

秘钥库里出现大量重复印记，守卫无法辨认真正的通行证。你用集合找出共同的徽记，打开通向星象塔的门。

教学：集合交集 & 取共同元素，并集 | 合并元素，差集 - 取仅属于左集合的元素。字典用键查询值；get 可以给缺失键一个默认值。

实践：改写字典版成绩系统，并比较列表与字典按姓名查询的方式。

## 第 15 关：符文 · 星象塔

巫师的求救信被混入无数杂乱字符。你需要用正则符文找出邮箱与手机，辨别真正的求救者。

教学：标准模块通过 import 调用。math.sqrt 求平方根；random.sample 无重复抽样；string.ascii_letters 提供字母。正则表达式描述文本模式：\d 数字、\w 单词字符、. 任意非换行字符、[] 字符集、+ 至少一次、* 零次以上、? 可选、{n} 重复 n 次、^/$ 起止、() 分组、| 或。Python 常写 r"模式"，避免反斜杠被字符串再次解释；re.search 查找，re.findall 提取，re.sub 替换，re.fullmatch 验证整个字符串。

实践：用标准库实现双色球抽样、邮箱/手机提取与等额本息月供计算；在下方匹配台实验。

## 第 16 关：辨识求救信号 · 星穹露台

天幕浮出许多伪造求救信。你用 fullmatch 验证完整的十一位号码，用 sub 抹去个人信息，收到艾琳真正的讯息：先知的契约藏在海的另一边。

教学：findall 适合从文本提取多个匹配；fullmatch 要求整个字符串符合模式。sub 用于替换或脱敏。基础邮箱规则只是教学近似，生产验证需结合业务规则。random 的伪随机适合游戏和抽样，不适合安全密钥。等额本息：A=P*r*(1+r)**n/((1+r)**n-1)，零利率时 A=P/n。

实践：用标准库实现双色球抽样、邮箱/手机提取与等额本息月供计算；在下方匹配台实验。

## 第 17 关：咒式 · 工匠庭院

实践：实现薪资函数，展示位置/关键字调用，解释参数传递与高内聚低耦合。

## 第 25 关：风信 · 气象灯塔

渡海前必须查天气。灯塔通过 API 获取消息，而不是猜测远方的风暴。

教学：HTTP 请求有 URL、方法、参数与状态码。Requests 的 get 获取数据；设置 timeout，raise_for_status 检查错误，json 解析响应。遵守服务条款、频率限制与隐私边界。本游戏示例离线展示，不发起真实网络请求。

实践：调用可用天气 API 或合规爬虫，展示获取→检查→解析→呈现的数据流。

## 第 26 关：风暴中的响应 · 雾海信号岛

船队抵达信号岛，天气服务突然返回错误。你没有把失败当成晴天，而是检查状态、设置超时并等待可靠消息。艾琳终于在岛上与你会合。

教学：HTTP 200 常表示成功，404 表示资源不存在，429 通常表示请求过多。JSON 解析成功不保证字段完整；检查结构，处理 Requests 异常并遵守频率限制。

实践：调用可用天气 API 或合规爬虫，展示获取→检查→解析→呈现的数据流。

## 第 27 关：契约 · 先知之殿

先知愿意借给你智慧，却要求你守住居民的秘密。赛勒斯说：智慧的力量需要责任约束。

教学：大模型集成通常包含 endpoint、认证、模型、messages 与输出解析。密钥放在服务端环境变量；个人数据应最小化并征求必要授权。验证模型输出，关注版权和偏见。本关是离线教学示例，没有接入在线模型。

实践：实践开源模型 API 集成，撰写 500 字伦理报告，准备优秀项目答辩。

## 第 28 关：拒绝错误的契约 · 浮印契约厅

先知要求以所有居民的姓名和电话换取“完美答案”。艾琳揭示，它一直把不确定的回答伪装成预言。你拒绝契约，保护居民数据，取回最后的钥匙。

教学：对话历史会影响模型输出；要求引用与核验不等于结果必然正确。密钥不能放进前端或仓库。个人信息最小化，明确授权、用途和保存期限，并讨论生成代码版权与推荐算法偏见。

实践：实践开源模型 API 集成，撰写 500 字伦理报告，准备优秀项目答辩。

## 第 29 关：集结 · 龙眠城堡

城堡前，所有符文必须协作。把数据、函数、文件、API 连接成有明确目标的项目，才有力量打破诅咒。

教学：明确用户、需求、输入输出与验收标准；把项目拆成可完成的小任务，逐项验证。综合项目可选数据管理、自动化、智能对话或爬虫；答辩展示需求、模块、测试、AI 使用记录与局限。

实践：提交项目及测试记录，准备展示与答辩，独立解释 AI 辅助生成的代码。

## 第 30 关：破除城堡结界 · 十六符文大厅

你、艾琳与赛勒斯共同完成符文系统，读取证词、清洗数据、验证法术、保存报告。十六座石台逐一亮起，诺克斯的巢穴终于打开。

教学：验收标准必须与真实需求对应。综合项目需演示正常流程、边界输入与失败恢复；记录 AI 参与部分，并独立解释代码。声明未实现功能与数据局限。

实践：提交项目及测试记录，准备展示与答辩，独立解释 AI 辅助生成的代码。

## 第 31 关：黎明 · 最后的龙

诺克斯并不是知识的敌人，它被未经验证的咒语束缚。勇者以求证、责任与创造解除诅咒，让恶龙成为王国的守护者。

教学：复盘：IPO → 类型 → 流程 → 容器 → 模块/函数 → 文件 → 数据 → API → 大模型 → 综合应用。AI 可辅助生成、调试、优化，但理解、验证与责任由人承担。研究推荐算法等技术的便利、隐私、偏见和社会影响，形成有证据的反思。

实践：完成知识图谱复盘，提交关于推荐算法等技术社会影响的 800 字反思报告。

你没有以遗忘击败诺克斯，而是用被验证的知识解开它的束缚。恶龙成为守护者，艾琳回到星火村教新学徒，赛勒斯把最后一页留给你：持续学习，永远提问。
