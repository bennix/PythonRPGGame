03 THE SPELLBOOK

第 8 周 · 标准库 re

用一个模式，
找出整封信里的线索。

先认识 \d，用 {n} 指定重复次数；再用 re.findall 从一段文本里找到所有匹配。表达式不再像暗号，而是一种描述规律的方法。

字符集 [3-9]重复 \d{9}提取 findall
spellbook / message.pyPY
# 从巫师的信里找出手机号码
import re

message = "线索：13812345678"
pattern = r"1[3-9]\d{9}"

clues = re.findall(pattern, message)
print(clues)
# ['13812345678']
